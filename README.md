# つばめいと しゃしん（tsubameiAR）

つばめ祭（文化祭）のフォトスポット用Web AR。QRコードを読むとブラウザでカメラが起動し、清明高校のマスコット「つばめい」（3D）といっしょに写真がとれる。アプリのインストールやポスターは不要。

## 使い方

1. QRコードを読む → カメラが起動する（はじめにカメラの許可を求められたら「許可」）
2. つばめいを好きな位置・大きさにする
   - **1本の指でドラッグ**：うごかす
   - **2本の指でピンチイン／ピンチアウト**：小さく／大きくする（2本の指のまま動かすと移動も）
   - **「設定」ボタン**：スライダーで「大きさ・左右・上下・むき」を変える。タイマー（なし／3秒／5秒）もここで選ぶ。「もとにもどす」で最初の位置に戻る。「設定を おわる」で閉じる
3. まんなかの丸いボタンでシャッター → 「しゃしんを ほぞん」（iPhone・iPad は共有メニューの「画像を保存」）。共有できない端末は「ダウンロード」。画像の長おしでも保存できる

- **カメラの切りかえ**：右下の「カメラ」スイッチで「イン」「アウト」の押した側に切りかわる（選んでいる側が白くなる）。インカメラ（自撮り）は鏡に映したように左右反転して表示・保存する。選んだカメラは端末に記憶される
- つばめいの位置・大きさ、タイマーも端末に記憶される（係の端末で一度合わせておけば次も同じ）
- 写真は端末の中だけで作り、サーバーには送らない
- **フレーム**：画面の上の端に「令和8年 清明高校つばめ祭に参加しました」のバナーが出る（カメラ・つばめいより上）。写真にも同じ位置で入る。スマホ・iPad の縦向きは画面の幅いっぱい、横向きは高さが画面の3割までになるよう小さくして中央に置く。元の画像は `令和8年 清明高校つばめ祭バナー.png`、使っているのは上の部分を切り出した `assets/frame.webp`（大きさの決め方は `js/app.js` の `frameRect()`）

URLの末尾に `?camera=user`（イン）または `?camera=environment`（アウト）を付けると、最初に使うカメラを指定できる。

## ページ

| ページ | 内容 |
|---|---|
| `index.html` | カメラ画面（QRコードの行き先） |
| `qr.html` | 入口に貼るQRコード（印刷用）。来場者の自撮り用（インカメラ）と係用（アウトカメラ）の2枚 |
| `model.html` | つばめいの3Dモデルを回して見る（係用。ポーズを選んで止められる） |

## つばめいの3Dモデル

- 正面のイラスト `つばめい/つばめい (2).PNG` から作った3Dモデル（高さはとさかの先まで1.2m。くちばしは開かない）。絵を色ごとの部品に分け、輪郭をふくらませて立体にし、正面には元の絵を貼っている。横・後ろの形はデザインの線画 `つばめい/線画/` に合わせた
- 羽を広げるポーズ（手をふる・ばんざい・とぶ）では、ばんざいの絵 `つばめい (1).png` から作った「広げた羽」に入れかわる
- 約3.6秒ごとにポーズが変わる：立つ → 手をふる → ばんざい → てれる → とぶ。ときどきまばたきする
- 作り直し方：Python（numpy・pillow・scipy）で `python tools/build_tsubamei.py` を実行すると `assets/tsubamei/`（model.json・model.bin・front.png・back.png）ができる。動き・ポーズは `js/models/tsubamei.js`
- このモデルは dungeonAR（ダンジョンAR）の `tsubamei-v2` から移したもの

## しくみ

- カメラの映像（`<video>`）の上に、透明な three.js の画面を重ねてつばめいを描く。床や壁の認識はしない（位置と大きさは指とスライダーで合わせる）。そのため iPhone・iPad の Safari でも動く
- 位置と大きさは画面の割合で持つ（`js/app.js` の `place`）。撮影時は画面に見えている範囲をカメラの解像度のまま切り抜き、つばめいを同じ大きさで描いて重ねる

## バージョン

設定パネルのいちばん下に `ver 1.1.0（2026.10.21）` のように表示する。更新を公開するたびに `js/version.js` の `VERSION` と `RELEASED` を上げる（大きな作り直し＝1つ目、機能の追加＝2つ目、修正だけ＝3つ目）。当日、端末に古い画面が残っていないかの確認に使う。

## 公開方法（GitHub Pages）

1. GitHub のリポジトリで **Settings → Pages** を開く
2. **Source: Deploy from a branch**、**Branch: `main` / `(root)`** を選んで Save
3. 数分後に `https://hogepiyo57.github.io/tsubameiAR/` で公開される
4. 公開URLで `qr.html` を開き、QRコードを印刷する

カメラは https でしか動かないため、パソコンのファイルを直接開いて（`file://`）も動かない。

## 動作環境

- iPhone・iPad：Safari
- Android：Chrome
- 3D表示のライブラリ（three.js）とフォントはネットから読み込む（モバイルデータ通信で運用）

## 構成

```
index.html / qr.html / model.html   各ページ
css/style.css                       共通スタイル
js/app.js                           カメラ画面（指の操作・設定パネル・撮影）
js/camera.js                        カメラの起動と切りかえ
js/capture.js                       カウントダウン・撮影結果の保存
js/storage.js                       端末への記憶
js/version.js                       バージョン
js/models/tsubamei.js               つばめいの3Dモデルとポーズ
assets/tsubamei/                    3Dモデルのデータ（tools/build_tsubamei.py で作る）
assets/frame.webp                   フレーム（バナーの上の部分を切り出したもの）
assets/icon.png                     アイコン
つばめい/                            元のイラストと線画
tools/build_tsubamei.py             3Dモデルを作るスクリプト
```
